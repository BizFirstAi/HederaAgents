HederaAgents

Hedera Hashgraph community node for BizFirst.Ai — query accounts, tokens, topics, and transactions via the free Mirror Node REST API.

What it does: The Hedera node (hedera) exposes Mirror Node reads as BizFirst.Ai workflow operations across five resources — account, token, topic, transaction, and utility. No signing credential or SDK required for anything documented here — every operation is a free, eventually-consistent read.

Roadmap

Signed writes (account create/transfer, token mint/associate/transfer, topic create/submit, message sign) are next, following the same pattern as the reads above. They require the community Hashgraph .NET SDK, with the signing key resolved from a vault CRYPTO_WALLET credential.

About BizFirst.Ai

BizFirst.Ai is a workflow automation platform for building AI-driven business processes. This node is one of many community connectors that plug into its ProcessEngine — browse the full node catalogue and developer guides at docs.bizfirstai.com, or join the discussion at community.bizfirstai.com.
